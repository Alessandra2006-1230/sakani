# Optional fonts

Sakani looks best with two free Google fonts:

- **Playfair Display** (titles and big numbers)
- **DM Sans** (everything else)

Drop the **static** `.ttf` files here (for example `PlayfairDisplay-Bold.ttf`,
`DMSans-Regular.ttf`, `DMSans-Bold.ttf`) and restart the app. On Windows they
are loaded for Sakani only, with nothing installed on your computer. On macOS
or Linux, install the fonts normally instead.

If the fonts are not available, Sakani falls back to Georgia (titles) and
Segoe UI (body), so nothing breaks. Variable-font files may show only their
default weight, so prefer the static files.
